Guia de Início Rápido para Desenvolvedores

Configurando o ambiente unificado de desenvolvimento via CLI abrasileirado:

# 1. Clone o repositório workspace privado
git clone git@github.com:abrasileirado/workspace.git ~/projetos/PESSOAL/abrasileirado/workspace

# 2. Acesse o diretório do workspace
cd ~/projetos/PESSOAL/abrasileirado/workspace

# 3. Execute o setup inicial (clona repositórios e configura variáveis)
./abrasileirado setup

# 4. Abra o workspace unificado no VS Code
code abrasileirado.code-workspace

# 5. Inicie o ambiente Docker
abrasileirado launch

Arquitetura da Organização

Visão geral do padrão de repositórios e segregação de responsabilidades:

A organização Abrasileirado é mantida sob um modelo modular onde cada repositório atende a uma linguagem ou responsabilidade específica. O desenvolvimento local é centralizado no repositório privado workspace, garantindo que o ambiente Docker e os atalhos de desenvolvimento não poluam o código-fonte público de cada biblioteca.
